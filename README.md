# MX Notes — Statistic Notebook

A small responsive notebook web app to store words (team names, bets, etc.). It auto-saves locally in your browser and shows simple frequency statistics.

Features:
- Paste or type one item per line; auto-saves to localStorage.
- Live frequency list (counts per item).
- Export JSON or CSV, and import backups.
- Responsive layout for mobile and desktop.
- Ambient animated 9-color background.

To run locally:
1. Clone the repo.
2. Open `index.html` in a browser (or serve with any static server).

Planned improvements (you can ask me to implement any of these):
- Optional sync to GitHub Gist or remote storage.
- Tagging, filtering, or grouping items.
- Persistent theme toggle and print-friendly export.
